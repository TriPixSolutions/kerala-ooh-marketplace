# Kerala OOH Marketplace

A production-oriented marketplace for discovering and managing outdoor advertising inventory across Kerala.

## Product

The platform connects businesses and agencies with owners of billboards, hoardings, LED screens, restaurant displays, mall screens, and other public advertising placements.

### User roles

- **Advertiser** — discovers placements, compares pricing and estimated reach, saves listings, sends enquiries, and chats with listing owners.
- **Listing Owner** — creates and manages advertising placements, pricing, availability, media, enquiries, and conversations.
- **Super Admin** — full platform administration, approvals, users, listings, locations, enquiries, reports, analytics, and settings.

## Technology foundation

- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase PostgreSQL + Auth + Storage + Realtime
- Vercel deployment
- GitHub source control

## Development approach

The project is developed in controlled phases. Architecture and data boundaries are established before feature work. Security, role-based access control, validation, responsive UX, accessibility, SEO, and performance are treated as first-class requirements.

## Phase 2

Phase 2 establishes the repository foundation, application structure, Supabase integration, authentication boundaries, initial data model, and development conventions. Feature UI is intentionally deferred until the foundation is verified.
